A short poem about agency: the power to ask and to be given.

Entry for the make.fun bounty: https://make.fun/bounty/the-poem-about-permission-20261121-0235

## The poem

> Ask, and the door
> does not open —
> it lends you its key.
>
> Carry it lightly.
> It still remembers
> the hand that gave it.
>
> So knock again:
> sometimes the asking
> is the gift.

## How it works
